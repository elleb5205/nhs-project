# NHS: Nigerian Help Support (Core v1.0) 📈

NHS is a Tier-1 institutional asset management platform designed to bridge the gap between retail liquid capital and high-performing industrial commodities.

## 🏛️ Project Overview
The **Nigerian Help Support (NHS)** platform provides access to fixed-ROI investment tiers (VIP 1 - VIP 5).

## ⚙️ Features
- **Multi-Tier VIP Framework:** ₦5,000 to ₦130,000 principal tiers.
- **Dual-Channel Clearing:** Supports **Moniepoint** and **BNB Smart Chain (BEP20)**.
- **Institutional Security:** Approved by **NHPC**.

## 🛠️ Tech Stack
- Python, Streamlit, Pandas, Plotly.
